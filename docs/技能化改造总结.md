### 4. 工作流编排

创建工作流示例：

```bash
cat > workflows/collect_and_train.yaml <<EOF
name: 采集并训练工作流
steps:
  - name: 采集图片
    skill: ardc-collector
    script: collect_images.py
    args:
      role: "Arona"
      count: 200
      output: "./data/arona"
  
  - name: 数据清洗
    skill: ardc-cleaner
    script: deduplicate.py
    args:
      input: "./data/arona"
      output: "./data/arona_clean"
  
  - name: 训练模型
    skill: ardc-trainer
    script: train_model.py
    args:
      data-dir: "./data/arona_clean"
      model: "efficientnet_b3"
      epochs: 50
EOF
```
