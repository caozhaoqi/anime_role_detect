# Anime Role Detect Skills 使用指南

---

## 📋 快速开始

### 1. 安装技能

```bash
# 列出可用技能
python3 scripts/ardc-skill-sync.py list

# 安装数据采集技能
python3 scripts/ardc-skill-sync.py install ardc-collector

# 安装数据清洗技能
python3 scripts/ardc-skill-sync.py install ardc-cleaner

# 安装模型训练技能
python3 scripts/ardc-skill-sync.py install ardc-trainer

# 安装角色分类技能
python3 scripts/ardc-skill-sync.py install ardc-classifier
```

### 2. 配置环境

创建 `.env` 文件：

```bash
cat > .env <<'EOF'
# 服务配置
ARDC_BASE_URL=http://localhost:8080
ARDC_API_KEY=your_api_key_here
ARDC_TOKEN=your_token_here

# 可选：环境标识
# ARDC_ENV=dev  # dev/prod
EOF
```

### 3. 运行技能

#### 数据采集

```bash
# 采集单个角色图片
python3 skills/ardc-collector/scripts/collect_images.py \
    --role "Arona" \
    --count 100 \
    --output ./data/arona

# 爬取 URL
python3 skills/ardc-collector/scripts/crawl_urls.py \
    --keyword "blue archive" \
    --source "danbooru" \
    --output ./urls/blue_archive.txt

# 批量下载图片
python3 skills/ardc-collector/scripts/download_batch.py \
    --url-file ./urls/blue_archive.txt \
    --output ./data/blue_archive \
    --concurrent 10
```

#### 数据清洗

```bash
# 去重
python3 skills/ardc-cleaner/scripts/deduplicate.py \
    --input ./data/raw_images \
    --output ./data/clean_images

# 质量检查
python3 skills/ardc-cleaner/scripts/check_quality.py \
    --input ./data/clean_images \
    --min-quality 0.8 \
    --output ./data/high_quality

# 数据集合并
python3 skills/ardc-cleaner/scripts/merge_datasets.py \
    --input-dir ./data/source1 \
    --input-dir ./data/source2 \
    --output ./data/merged
```

#### 模型训练

```bash
# 训练模型
python3 skills/ardc-trainer/scripts/train_model.py \
    --data-dir ./data/training_data \
    --model efficientnet_b3 \
    --epochs 50 \
    --batch-size 32 \
    --output ./models/efficientnet_b3.pth

# 评估模型
python3 skills/ardc-trainer/scripts/evaluate_model.py \
    --model-path ./models/efficientnet_b3.pth \
    --test-dir ./data/test_data \
    --output ./results/evaluation.json

# 模型管理
python3 skills/ardc-trainer/scripts/manage_models.py \
    --list
```

#### 角色分类

```bash
# 单图分类
python3 skills/ardc-classifier/scripts/classify_image.py \
    --image ./test_images/test.jpg \
    --model efficientnet_b3 \
    --output ./results/classification.json

# 批量分类
python3 skills/ardc-classifier/scripts/classify_batch.py \
    --input ./test_images/ \
    --model efficientnet_b3 \
    --output ./results/batch_results.json

# 视频分类
python3 skills/ardc-classifier/scripts/classify_video.py \
    --video ./test_videos/test.mp4 \
    --model efficientnet_b3 \
    --output ./results/video_results.json
```

#### 以图搜图

```bash
# 构建索引
python3 skills/ardc-search/scripts/build_index.py \
    --data-dir ./data/character_images \
    --output ./index/faiss_index.bin

# 搜索相似图片
python3 skills/ardc-search/scripts/search_similar.py \
    --query-image ./query/query.jpg \
    --index ./index/faiss_index.bin \
    --top-k 10 \
    --output ./results/search_results.json
```

## 🎯 技能详解

### 1. ardc-collector - 数据采集技能

**功能**：批量采集动漫/游戏角色图片

**使用场景**：
- 从多个来源采集角色图片
- 构建数据集
- 补充现有数据集

**常用命令**：

```bash
# 采集指定角色
python3 skills/ardc-collector/scripts/collect_images.py \
    --role "Arona" \
    --count 200 \
    --output ./data/arona

# 爬取多个关键词
python3 skills/ardc-collector/scripts/crawl_urls.py \
    --keyword-file ./keywords/characters.txt \
    --output ./urls/all_urls.txt
```

### 2. ardc-cleaner - 数据清洗技能

**功能**：清洗和处理采集的数据

**使用场景**：
- 去除重复图片
- 过滤低质量图片
- 统一图片格式和命名

**常用命令**：

```bash
# 去重并标准化
python3 skills/ardc-cleaner/scripts/deduplicate_and_normalize.py \
    --input ./data/raw \
    --output ./data/clean \
    --format jpeg \
    --size 224x224

# 检查损坏图片
python3 skills/ardc-cleaner/scripts/check_corrupted_images.py \
    --input ./data/images \
    --output ./logs/corrupted.txt
```

### 3. ardc-trainer - 模型训练技能

**功能**：训练和管理角色分类模型

**使用场景**：
- 训练新模型
- 微调现有模型
- 模型评估和比较

**常用命令**：

```bash
# 使用优化参数训练
python3 skills/ardc-trainer/scripts/train_model.py \
    --data-dir ./data/training \
    --model efficientnet_b3 \
    --epochs 50 \
    --batch-size 32 \
    --lr 0.001 \
    --augmentation \
    --early-stopping

# 交叉验证
python3 skills/ardc-trainer/scripts/train_model.py \
    --data-dir ./data/training \
    --model resnet50 \
    --cross-validation 5
```

### 4. ardc-classifier - 角色分类技能

**功能**：识别图片中的角色

**使用场景**：
- 单张图片识别
- 批量图片分类
- 视频帧分析

**常用命令**：

```bash
# 详细输出
python3 skills/ardc-classifier/scripts/classify_image.py \
    --image ./test.jpg \
    --model efficientnet_b3 \
    --verbose \
    --top-k 5

# 批量处理并生成报告
python3 skills/ardc-classifier/scripts/classify_batch.py \
    --input ./images/ \
    --model efficientnet_b3 \
    --output ./results/ \
    --generate-report
```

### 5. ardc-search - 以图搜图技能

**功能**：基于图片特征搜索相似图片

**使用场景**：
- 查找相似角色图片
- 图片去重
- 数据集检索

**常用命令**：

```bash
# 搜索并显示结果
python3 skills/ardc-search/scripts/search_similar.py \
    --query-image ./query.jpg \
    --index ./index/faiss_index.bin \
    --top-k 5 \
    --show-results

# 更新索引
python3 skills/ardc-search/scripts/manage_faiss.py \
    --index ./index/faiss_index.bin \
    --add ./new_images/
```

## 🔄 工作流编排

### 创建工作流

```yaml
# workflows/collect_train_deploy.yaml
name: 采集→训练→部署工作流
description: 自动完成数据采集、清洗、训练和部署

steps:
  - name: 采集数据
    skill: ardc-collector
    script: collect_images.py
    args:
      role: "New Character"
      count: 200
      output: "./data/new_character"
  
  - name: 数据清洗
    skill: ardc-cleaner
    script: deduplicate_and_normalize.py
    args:
      input: "./data/new_character"
      output: "./data/clean_character"
      format: "jpeg"
      size: "224x224"
  
  - name: 训练模型
    skill: ardc-trainer
    script: train_model.py
    args:
      data-dir: "./data/clean_character"
      model: "efficientnet_b3"
      epochs: 50
      output: "./models/new_model.pth"
  
  - name: 评估模型
    skill: ardc-trainer
    script: evaluate_model.py
    args:
      model-path: "./models/new_model.pth"
      test-dir: "./data/test"
      output: "./results/evaluation.json"
  
  - name: 部署模型
    skill: ardc-classifier
    script: deploy_model.py
    args:
      model-path: "./models/new_model.pth"
      endpoint: "/api/classify/v2"
```

### 执行工作流

```bash
# 执行工作流
python3 scripts/run_workflow.py --workflow workflows/collect_train_deploy.yaml

# 后台执行
nohup python3 scripts/run_workflow.py --workflow workflows/collect_train_deploy.yaml > ./logs/workflow.log 2>&1 &

# 查看日志
tail -f ./logs/workflow.log
```

## 📊 示例：完整的角色分类流程

### 步骤 1：采集数据

```bash
# 创建数据目录
mkdir -p ./data/arona

# 采集 Arona 的图片
python3 skills/ardc-collector/scripts/collect_images.py \
    --role "Arona" \
    --count 200 \
    --output ./data/arona
```

### 步骤 2：数据清洗

```bash
# 创建清洗后目录
mkdir -p ./data/arona_clean

# 去重和质量过滤
python3 skills/ardc-cleaner/scripts/deduplicate.py \
    --input ./data/arona \
    --output ./data/arona_clean

# 检查质量
python3 skills/ardc-cleaner/scripts/check_quality.py \
    --input ./data/arona_clean \
    --min-quality 0.7 \
    --output ./data/arona_high_quality
```

### 步骤 3：准备训练数据

```bash
# 创建训练/验证/测试目录
mkdir -p ./data/training/Arona
mkdir -p ./data/validation/Arona
mkdir -p ./data/test/Arona

# 划分数据集 (80%训练, 10%验证, 10%测试)
python3 skills/ardc-cleaner/scripts/prepare_training_data.py \
    --input ./data/arona_high_quality \
    --output ./data \
    --train-ratio 0.8 \
    --val-ratio 0.1
```

### 步骤 4：训练模型

```bash
# 创建模型目录
mkdir -p ./models

# 训练模型
python3 skills/ardc-trainer/scripts/train_model.py \
    --data-dir ./data \
    --model efficientnet_b3 \
    --epochs 50 \
    --batch-size 32 \
    --lr 0.001 \
    --output ./models/arona_model.pth
```

### 步骤 5：测试模型

```bash
# 创建结果目录
mkdir -p ./results

# 评估模型
python3 skills/ardc-trainer/scripts/evaluate_model.py \
    --model-path ./models/arona_model.pth \
    --test-dir ./data/test \
    --output ./results/arona_evaluation.json

# 测试单张图片
python3 skills/ardc-classifier/scripts/classify_image.py \
    --image ./test_images/arona_test.jpg \
    --model-path ./models/arona_model.pth \
    --output ./results/single_prediction.json
```

## ⚙️ 高级配置

### 多环境配置

```bash
# 开发环境
export ARDC_ENV=dev
python3 skills/ardc-collector/scripts/collect_images.py --role "Arona"

# 生产环境
export ARDC_ENV=prod
python3 skills/ardc-classifier/scripts/classify_batch.py --input ./images/
```

**环境配置文件示例**：

```bash
# .env.dev
ARDC_BASE_URL=http://localhost:8080
ARDC_API_KEY=dev_key
ARDC_TOKEN=dev_token

# .env.prod
ARDC_BASE_URL=https://api.anime-role-detect.io
ARDC_API_KEY=prod_key
ARDC_TOKEN=prod_token
```

### 自定义配置路径

```bash
# 使用自定义配置文件
export ARDC_PROJECT_ENV_FILE=/path/to/custom/.env
python3 skills/ardc-collector/scripts/collect_images.py --role "Arona"

# 或通过命令行指定
python3 skills/ardc-collector/scripts/collect_images.py \
    --role "Arona" \
    --config /path/to/custom/.env
```

### 日志配置

```bash
# 设置日志级别
export ARDC_LOG_LEVEL=DEBUG
python3 skills/ardc-collector/scripts/collect_images.py --role "Arona"

# 设置日志目录
export ARDC_LOG_DIR=./logs
python3 skills/ardc-collector/scripts/collect_images.py --role "Arona"
```

## 🛠️ 常见问题

### Q1: 技能安装失败？

```bash
# 确保目录存在且有写入权限
mkdir -p ~/.ardc/skills
chmod 755 ~/.ardc/skills

# 检查网络连接
ping skills.anime-role-detect.io

# 手动安装
cp -r /path/to/ardc-collector ~/.ardc/skills/
```

### Q2: 环境变量不生效？

```bash
# 检查配置文件路径
echo $ARDC_PROJECT_ENV_FILE

# 检查文件内容
cat .env

# 确保没有语法错误
grep -E "^[^#]*=" .env
```

### Q3: 模型训练速度慢？

```bash
# 使用 GPU 加速
export CUDA_VISIBLE_DEVICES=0
python3 skills/ardc-trainer/scripts/train_model.py --data-dir ./data

# 调整批次大小
python3 skills/ardc-trainer/scripts/train_model.py \
    --data-dir ./data \
    --batch-size 64

# 使用混合精度训练
python3 skills/ardc-trainer/scripts/train_model.py \
    --data-dir ./data \
    --mixed-precision
```

### Q4: 分类结果不准确？

```bash
# 增加训练数据
python3 skills/ardc-collector/scripts/collect_images.py \
    --role "Arona" \
    --count 500

# 调整模型参数
python3 skills/ardc-trainer/scripts/train_model.py \
    --data-dir ./data \
    --epochs 100 \
    --lr 0.0001

# 使用更强大的模型
python3 skills/ardc-trainer/scripts/train_model.py \
    --data-dir ./data \
    --model efficientnet_b7
```
