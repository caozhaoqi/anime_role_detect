## 1. 问题本质

训练集与测试集**同源自 `data/final_dataset`**：测试用的「每类 25 张」是从训练同批图像里抽的，
导致官方指标 84% 含「同图自测」水分（同一张图既训练又测试）。

## 2. 量化结论（三级口径）

| 口径 | 方法 | Top-1 | 说明 |
|---|---|---|---|
| ① 官方基准（完全泄漏） | final_dataset 抽 25/类，与训练同批 | **84.01%** | README 现称的 84%，含同图自测水分 |
| ② 切分 test·真实逐图泛化 | 70/15/15 无交叠切分，test 永不参与训练 | **82.65%** | 剔除同批图后仅降 1.65pp → **逐图泛化真实** |
| ③ v2 干净重训（欠训练下界） | 同 ② 切分，但仅 6–8 epoch / 关 AutoAugment / 头重置 / 1560 图 | **55%** | 方法学下界，**非泛化上限** |

**关键判断**：同图泄漏的「水分」只有约 1.65 个百分点，模型对已知 51 类的逐图泛化是真实的；
84% 虚高程度有限，并非类级过拟合。③ 的 55% 是训练不充分导致，不能当作真实泛化能力。

## 3. 已具备的资产

- 干净切分脚本：`scripts/model_evaluation/make_split.py`（seed=42, 70/15/15 分层, 无交叠 → `data/splits/seed42/`）
- 干净重训脚本：`scripts/model_evaluation/train_clean_split.py`（复用原配方；产物写 `models/efficientnet_b3_v2/`，**不覆盖现模型**；训完自动 `eval_on_manifest.py` 评测）
- 评测脚本：`scripts/model_evaluation/eval_on_manifest.py`

## 4. 推荐处置（按优先级，来自 leakage_report 建议）

1. **立即采用 ② 82.65% 作为对外口径**：在 README/文档把「Top-1 84%」修正为
   「Top-1 82.65%（无交叠切分逐图泛化；原 84% 含同图自测）」。零成本、诚实。
2. **（可选）跑完整配方干净重训**拿真实泛化上限：用 `train_clean_split.py` 但按原模型配方
   （~45 epoch + AutoAugment + Mixup + label smoothing + 余弦重启），预期落在 82–84% 区间，
   作为正式泛化基线。
3. **（长期）采集真正独立的外源测试集**（与 final_dataset 零交叠）做最严谨评测。
