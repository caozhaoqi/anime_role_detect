# Anime Role Detect 技能仓库部署指南

## 概述

本文档详细描述如何在公网服务器上部署 ARD（Anime Role Detect）技能仓库，使其他用户可以下载和使用您发布的技能。

## 环境要求

### 硬件要求
- CPU: 2核及以上
- 内存: 4GB及以上
- 存储: 10GB及以上可用空间

### 软件要求
- Python 3.8+
- pip 20.0+
- Git
- Nginx（可选，用于反向代理）

## 部署步骤

### 1. 克隆代码仓库

```bash
git clone https://github.com/your-username/anime_role_detect.git
cd anime_role_detect
```

### 2. 创建虚拟环境

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. 安装依赖

```bash
pip install -r requirements.txt
pip install -e .
```

### 4. 启动 API 服务

#### 开发模式（用于测试）

```bash
python -m ardc.api.main
```

#### 生产模式

使用 uvicorn 启动：

```bash
uvicorn ardc.api.main:app --host 0.0.0.0 --port 8000 --workers 4
```

#### 使用 systemd 管理服务（推荐）

创建服务文件 `/etc/systemd/system/ardc.service`：

```ini
[Unit]
Description=ARD Skill Repository API
After=network.target

[Service]
User=www-data
WorkingDirectory=/path/to/anime_role_detect
Environment="PATH=/path/to/anime_role_detect/venv/bin"
ExecStart=/path/to/anime_role_detect/venv/bin/uvicorn ardc.api.main:app --host 0.0.0.0 --port 8000 --workers 4
Restart=always

[Install]
WantedBy=multi-user.target
```

启动服务：

```bash
sudo systemctl daemon-reload
sudo systemctl enable ardc
sudo systemctl start ardc
```

### 5. 配置 Nginx 反向代理（可选）

创建 Nginx 配置文件 `/etc/nginx/sites-available/ardc`：

```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # 配置 HTTPS（使用 Let's Encrypt）
    # listen 443 ssl;
    # ssl_certificate /etc/letsencrypt/live/your-domain.com/fullchain.pem;
    # ssl_certificate_key /etc/letsencrypt/live/your-domain.com/privkey.pem;
}
```

启用配置：

```bash
sudo ln -s /etc/nginx/sites-available/ardc /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

### 6. 启动 Prometheus 监控

默认情况下，监控服务会在端口 8000 上一起启动。访问 `http://your-domain.com:8000/metrics` 查看指标。

## API 接口

### 基础 URL

```
http://your-domain.com/api/
```

### 接口列表

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | `/skills` | 获取技能列表 |
| GET | `/skills/{skill_id}` | 获取技能详情 |
| POST | `/skills` | 注册新技能 |
| DELETE | `/skills/{skill_id}` | 删除技能 |
| GET | `/skills/{skill_id}/versions` | 获取技能版本列表 |
| POST | `/skills/{skill_id}/install` | 安装技能 |
| DELETE | `/skills/{skill_id}/uninstall` | 卸载技能 |
| GET | `/search?keyword=xxx` | 搜索技能 |
| GET | `/tags` | 获取所有标签 |
| GET | `/categories` | 获取所有分类 |
| GET | `/stats` | 获取统计信息 |

### 注册技能示例

```bash
curl -X POST http://your-domain.com/api/skills \
  -H "Content-Type: application/json" \
  -d '{
    "id": "ardc-my-skill",
    "name": "我的技能",
    "version": "1.0.0",
    "description": "这是一个示例技能",
    "author": "your-name",
    "category": "utility",
    "entry_point": "scripts/main.py",
    "tags": ["示例", "工具"],
    "release_notes": "初始版本"
  }'
```

### 搜索技能示例

```bash
curl "http://your-domain.com/api/search?keyword=采集&limit=10"
```

## CLI 使用

### 安装 CLI

```bash
pip install -e .
```

### 命令列表

```bash
# 安装技能
ardc skill install ardc-collector

# 列出已安装技能
ardc skill list --installed

# 搜索技能
ardc skill search 采集

# 注册技能
ardc skill register \
  --id ardc-my-skill \
  --name "我的技能" \
  --version 1.0.0 \
  --author "your-name" \
  --category utility \
  --entry-point scripts/main.py

# 查看版本历史
ardc version history ardc-collector

# 版本回滚
ardc version rollback ardc-collector 1.0.0
```

## 安全配置

### 防火墙设置

```bash
# 允许 HTTP/HTTPS 访问
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

# 如果直接访问 API，允许 8000 端口
sudo ufw allow 8000/tcp

sudo ufw enable
```

### 访问控制

可以在 API 层面添加认证机制，例如使用 API Key：

```python
# ardc/api/main.py
async def get_api_key(api_key: str = Header(None)):
    if api_key != "your-secret-key":
        raise HTTPException(status_code=403, detail="Invalid API Key")
```

## 数据存储

默认数据存储路径：
- 注册表: `~/.ardc/registry.json`
- 索引: `~/.ardc/skill_index.json`
- 技能文件: `~/.ardc/skills/`
- 版本信息: `~/.ardc/versions/`
- 工作流: `~/.ardc/workflows/`

## 故障排查

### 服务无法启动

检查日志：
```bash
sudo journalctl -u ardc -f
```

### API 无法访问

检查端口是否开放：
```bash
nc -zv localhost 8000
```

### 技能安装失败

检查技能 ID 是否正确，以及网络连接是否正常。

## 常见问题

**Q: 如何添加新技能？**

A: 使用 `ardc skill register` 命令或调用 `/api/skills` POST 接口。

**Q: 如何发布新版本？**

A: 使用相同的技能 ID 和不同的版本号注册即可。

**Q: 如何卸载技能？**

A: 使用 `ardc skill uninstall <skill_id>` 命令。

**Q: 监控指标在哪里查看？**

A: 访问 `http://your-domain.com:8000/metrics`。
