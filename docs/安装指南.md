## 📋 安装要求

- **Python 3.8+**（系统需已安装）
- **网络连接**（用于下载技能包，离线模式也可使用）
- **操作系统**：macOS 10.14+ / Linux / Windows 10+

---

## 🎯 快速开始

### 1. 登录认证

```bash
ardc-skill-sync login
```

首次使用需要扫码登录认证，系统会显示二维码地址，使用 ARDC 客户端扫码即可完成认证。

### 2. 查看技能列表

```bash
ardc-skill-sync list
```

显示 SkillHub 上所有已发布的技能，包括已安装和未安装的技能。

### 3. 安装技能

```bash
# 安装最新版本
ardc-skill-sync install ardc-collector

# 安装指定版本
ardc-skill-sync install ardc-trainer --version 2.0.0
```

### 4. 检查更新

```bash
ardc-skill-sync check
```

检查已安装技能是否有新版本可用。

### 5. 同步更新

```bash
ardc-skill-sync sync
```

自动更新所有已安装的技能到最新版本。

## 📖 命令详解

| 命令 | 说明 | 示例 |
|------|------|------|
| `login` | 首次扫码认证 | `ardc-skill-sync login` |
| `status` | 显示本地配置状态 | `ardc-skill-sync status` |
| `check` | 检查技能更新 | `ardc-skill-sync check` |
| `sync` | 同步更新所有技能 | `ardc-skill-sync sync` |
| `list` | 查询技能列表 | `ardc-skill-sync list` |
| `install` | 安装指定技能 | `ardc-skill-sync install ardc-collector` |
| `uninstall` | 卸载指定技能 | `ardc-skill-sync uninstall ardc-collector` |
| `version` | 显示版本信息 | `ardc-skill-sync version` |
| `help` | 显示帮助信息 | `ardc-skill-sync help` |

### install 命令选项

```bash
ardc-skill-sync install <skill_name> [--version <版本号>]

# 示例
ardc-skill-sync install ardc-collector
ardc-skill-sync install ardc-trainer --version 1.0.0
```

## 📁 文件结构

```
~/.ardc/
├── config.json          # 配置文件
├── token.txt            # 认证 Token
└── skills/              # 技能目录
    ├── ardc-collector/  # 数据采集技能
    ├── ardc-cleaner/    # 数据清洗技能
    └── ...
```

## ⚙️ 配置文件

配置文件 `~/.ardc/config.json` 用于自定义技能同步工具的行为：

```json
{
  "skill_hub_url": "http://47.79.91.89:8888",
  "timeout": 30,
  "log_level": "INFO",
  "auto_update": true
}
```

### 配置项说明

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `skill_hub_url` | SkillHub 服务器地址 | `http://47.79.91.89:8888` |
| `timeout` | 请求超时时间（秒） | `30` |
| `log_level` | 日志级别 | `INFO` |
| `auto_update` | 是否自动检查更新 | `true` |

### 修改服务器地址

如果需要连接到其他 SkillHub 服务器，可以修改配置文件：

```bash
# 编辑配置文件
nano ~/.ardc/config.json

# 修改 skill_hub_url 字段
{
  "skill_hub_url": "http://your-server-ip:port"
}
```

### 环境变量覆盖

也可以通过环境变量临时覆盖配置：

```bash
# 临时使用指定服务器
export ARDC_SKILL_HUB_URL=http://another-server:8888
ardc-skill-sync list

# 永久设置（添加到 ~/.bashrc）
echo 'export ARDC_SKILL_HUB_URL=http://your-server:8888' >> ~/.bashrc
source ~/.bashrc
```

## 🔧 手动安装

如果一键安装脚本失败，可以手动安装：

### 步骤 1：创建目录

```bash
mkdir -p ~/.ardc/skills
mkdir -p ~/.local/bin
```

### 步骤 2：下载工具

```bash
curl -fsSL -o ~/.local/bin/ardc-skill-sync \
    https://47.79.91.89:8888/api/install/ardc-skill-sync.py
chmod +x ~/.local/bin/ardc-skill-sync
```

### 步骤 3：添加环境变量

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

## 🔐 认证机制

### Token 管理

- 登录成功后，Token 会保存到 `~/.ardc/token.txt`
- Token 有效期为 30 天，过期后需要重新登录
- 可以通过 `ardc-skill-sync login` 刷新 Token

### 离线模式

如果无法连接到 SkillHub 服务器，工具会自动进入离线模式：
- 使用本地缓存的技能列表
- 支持离线安装（创建空的技能目录结构）

## ⚠️ 常见问题

### Q1: 命令找不到？

```bash
# 确保环境变量已生效
source ~/.bashrc  # 或 source ~/.zshrc

# 或使用完整路径
python3 ~/.local/bin/ardc-skill-sync.py list
```

### Q2: Python 版本不足？

```bash
# macOS 使用 Homebrew 升级
brew install python3

# Ubuntu/Debian
sudo apt update && sudo apt install python3.8

# CentOS/RHEL
sudo yum install python38
```

### Q3: 安装失败？

```bash
# 检查网络连接
ping 47.79.91.89:8888

# 检查权限
ls -la ~/.ardc
ls -la ~/.local/bin

# 手动创建目录
mkdir -p ~/.ardc/skills
chmod 755 ~/.ardc
```

### Q4: 技能安装后无法使用？

```bash
# 检查技能目录
ls ~/.ardc/skills/ardc-collector

# 检查脚本是否可执行
ls -la ~/.ardc/skills/ardc-collector/scripts/
```
