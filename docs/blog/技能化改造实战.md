## 📖 前言

在现代软件开发中，我们常常面临这样的困境：
- 项目脚本越来越多，难以管理和维护
- 代码复用困难，相同功能重复实现

## 🛠️ 实现步骤

### 第一步：创建核心客户端

**文件**: `skills/ardc-client/scripts/ard_client.py`

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
Anime Role Detect 核心客户端模块
"""
import os
import sys
import requests

def load_env(env_path=None):
    """
    加载 .env 环境配置
    支持多环境：.env, .env.dev, .env.prod
    """
    env = {
        'ARDC_BASE_URL': os.environ.get('ARDC_BASE_URL', ''),
        'ARDC_API_KEY': os.environ.get('ARDC_API_KEY', ''),
        'ARDC_TOKEN': os.environ.get('ARDC_TOKEN', ''),
    }
    
    # 按优先级查找配置文件
    env_paths = ['.env', 'config/.env']
    if os.environ.get('ARDC_ENV'):
        env_paths.insert(0, f'.env.{os.environ["ARDC_ENV"]}')
    
    for candidate in env_paths:
        if os.path.exists(candidate):
            with open(candidate) as f:
                for line in f:
                    if '=' in line and not line.startswith('#'):
                        k, v = line.split('=', 1)
                        env[k.strip()] = v.strip()
            break
    
    return env

def call_api(base_url, token, endpoint, body=None):
    """统一 API 调用接口"""
    headers = {
        'Authorization': f'Bearer {token}',
        'Content-Type': 'application/json',
    }
    
    resp = requests.post(
        f"{base_url}{endpoint}",
        json=body or {},
        headers=headers,
        timeout=(10, 60),
    )
    
    return resp.json()
```

**设计要点**：
- 支持多环境配置文件
- 自动从多个位置查找配置
- 统一的 API 调用封装

**采集脚本** (`collect_images.py`)：

```python
#!/usr/bin/env python3
import sys
import os
import argparse

# 导入核心客户端
sys.path.insert(0, os.path.join(
    os.path.dirname(__file__),
    '..', '..', 'ardc-client', 'scripts'
))

from ard_client import load_env, call_api

def collect_images(role, count=100, output_dir='./data'):
    env = load_env()
    base_url = env.get('ARDC_BASE_URL', 'http://localhost:8080')
    token = env.get('ARDC_TOKEN', '')
    
    result = call_api(base_url, token, '/api/collect', {
        'role': role,
        'count': count,
        'output_dir': output_dir,
    })
    
    return result

if __name__ == '__main__':
    parser = argparse.ArgumentParser()
    parser.add_argument('--role', required=True)
    parser.add_argument('--count', type=int, default=100)
    parser.add_argument('--output', default='./data')
    
    args = parser.parse_args()
    collect_images(args.role, args.count, args.output)
```

### 第三步：创建技能管理工具

**文件**: `scripts/ardc-skill-sync.py`

```python
#!/usr/bin/env python3
import argparse
from pathlib import Path

SKILL_DIR = Path.home() / '.ardc' / 'skills'

def list_skills():
    """列出所有可用技能"""
    print("可用技能列表:")
    print("-" * 60)
    
    if SKILL_DIR.exists():
        for skill_path in SKILL_DIR.iterdir():
            if skill_path.is_dir():
                print(f"  ✓ {skill_path.name}")

def install_skill(skill_name):
    """安装指定技能"""
    print(f"安装 {skill_name}...")
    skill_dir = SKILL_DIR / skill_name
    skill_dir.mkdir(parents=True, exist_ok=True)
    print(f"✓ 已安装 {skill_name}")

def main():
    parser = argparse.ArgumentParser()
    subparsers = parser.add_subparsers(dest='command')
    
    subparsers.add_parser('list', help='列出技能')
    install_parser = subparsers.add_parser('install', help='安装技能')
    install_parser.add_argument('skill', help='技能名称')
    
    args = parser.parse_args()
    
    if args.command == 'list':
        list_skills()
    elif args.command == 'install':
        install_skill(args.skill)

if __name__ == '__main__':
    main()
```

## 🎮 使用方法

### 1. 环境配置

创建 `.env` 文件：

```bash
cat > .env <<EOF
ARDC_BASE_URL=http://localhost:8080
ARDC_API_KEY=your_api_key
ARDC_TOKEN=your_token
EOF
```

### 2. 安装技能

```bash
# 列出可用技能
python3 scripts/ardc-skill-sync.py list

# 安装数据采集技能
python3 scripts/ardc-skill-sync.py install ardc-collector
```

### 3. 运行技能

```bash
# 采集角色图片
python3 skills/ardc-collector/scripts/collect_images.py \
    --role "Arona" \
    --count 100 \
    --output ./data/arona

# 数据清洗
python3 skills/ardc-cleaner/scripts/deduplicate.py \
    --input ./data/arona \
    --output ./data/arona_clean

# 训练模型
python3 skills/ardc-trainer/scripts/train_model.py \
    --data-dir ./data/arona_clean \
    --model efficientnet_b3
```

### 4. 工作流编排

创建 `workflows/collect_and_train.yaml`：

```yaml
name: 采集并训练工作流
description: 自动完成数据采集、清洗和训练

steps:
  - name: 采集图片
    skill: ardc-collector
    script: collect_images.py
    args:
      role: "Arona"
      count: 200
      output: "./data/arona"
  
  - name: 数据清洗
    skill: ardc-cleaner
    script: deduplicate.py
    args:
      input: "./data/arona"
      output: "./data/arona_clean"
  
  - name: 训练模型
    skill: ardc-trainer
    script: train_model.py
    args:
      data-dir: "./data/arona_clean"
      model: "efficientnet_b3"
      epochs: 50
```

执行工作流：

```bash
python3 scripts/run_workflow.py --workflow workflows/collect_and_train.yaml
```

## 🔬 原理分析

### 环境配置加载流程

```
用户代码
    │
    ▼
load_env() 调用
    │
    ├─► 检查 ARDC_ENV 环境变量
    │       │
    │       ▼
    │   构建查找路径列表
    │       │
    │       ▼
    │   .env.<ARDC_ENV>
    │   config/.env.<ARDC_ENV>
    │   .env
    │   config/.env
    │       │
    │       ▼
    │   按优先级查找并加载
    │       │
    │       ▼
    │   返回环境配置字典
    │
    ▼
使用配置调用 API
```

### 技能调用机制

```
技能脚本
    │
    ├─► 导入 ard_client
    │       │
    │       ▼
    │   load_env() 获取配置
    │       │
    │       ▼
    │   call_api() 发送请求
    │       │
    │       ▼
    │    API Server
    │       │
    │       ▼
    │   返回 JSON 响应
    │
    ▼
处理响应并返回结果
```

### 工作流执行原理

```
工作流文件 (YAML)
    │
    ▼
解析工作流定义
    │
    ▼
遍历 steps
    │
    ├─► step 1: 调用 ardc-collector
    │       │
    │       ▼
    │   subprocess.run([python, script.py, --args])
    │       │
    │       ▼
    │   等待完成
    │
    ├─► step 2: 调用 ardc-cleaner
    │       │
    │       ▼
    │   subprocess.run([python, script.py, --args])
    │
    └─► step 3: 调用 ardc-trainer
            │
            ▼
        subprocess.run([python, script.py, --args])
```
