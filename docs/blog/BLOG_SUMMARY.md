## 🚀 快速开始

### 1. 环境准备

```bash
# 安装依赖
pip install -r requirements.txt

# 启动 Redis 和 PostgreSQL
docker-compose up -d redis postgres
```

### 2. 启动服务

```bash
# 启动模型服务
python -m uvicorn src.services.model_service.app:app --host 0.0.0.0 --port 8888

# 启动后端服务
python -m uvicorn src.api.app:app --host 0.0.0.0 --port 8001

# 启动 API 网关
python -m uvicorn src.services.api_gateway.app:app --host 0.0.0.0 --port 8000
```

### 3. 一键部署（推荐）

```bash
# 使用 Docker Compose 一键启动所有服务
docker-compose up -d
```

## 📈 核心功能

1. **角色识别**：支持65+二次元角色的精准识别
2. **多角色检测**：使用YOLOv8检测图片中的多个角色
3. **NSFW过滤**：自动过滤敏感内容，支持置信度分级
4. **以图搜图**：基于Faiss向量索引的相似图片搜索
5. **实时反馈**：WebSocket推送识别进度
6. **缓存优化**：相同图片哈希直接返回结果，避免重复计算
